
# Problem
Given...
    - Vector\<int>, piles

Return...
    - Bool

Where...
piles of rocks are in a row where the number of rocks in each pile is 
represented by piles\[i]. The goal of the game is to end with the most rocks.
A player can only take the first or last pile of rocks. Alice starts first.
Assuming they play optimally, return true if Alice wins, false if Bob wins.

[#877 Stone game](https://leetcode.com/problems/stone-game/description/)

## Constraint
- 2 <= piles.length <= 500
- piles.length is even
- 1 <= piles\[i] <= 500
- sum\(piles\[i]) is odd
