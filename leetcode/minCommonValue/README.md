
# Problem
Given...
    - Vector\<int> nums1
    - Vector\<int> nums2

Return...
    - Integer

Where...
Both arrays are sorted in non-decreasing order. Return the minimum common 
integer to both arrays, if no common integer exists return -1.
An integer is common if it has at least one occurence in both arrays.

[#2540 Minimum common value](https://leetcode.com/problems/minimum-common-value/description/?envType=daily-question&envId=2026-05-19)

## Constraint
- 1 <= nums1.length , nums2.length <= 10^5
- 1 <= nums1\[i], nums2\[j] <= 10^9
- Both nums1 and nums2 are sorted in non-decreasing order
