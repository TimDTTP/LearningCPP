
# Problem
Given...
    - Vector\<int> nums
    - Integer limit 

Return...
    - Integer

Where...
An array is complementary if the sum of the 2 values 
nums\[i] + nums\[n - 1 - i] is equal to all other indices. With each move, you
can replace any integer in nums with another integer between 1 and limit, 
inclusive. Return the minimum number of moves required to make nums
complementary.

[#1674 Minimum moves to make array complementary](https://leetcode.com/problems/minimum-moves-to-make-array-complementary/description/?envType=daily-question&envId=2026-05-13)

## Constraint
- n == nums.length
- 2 <= n <= 10^5
- 1 <= nums\[i] <= limit <= 10^5
- n is even
